# Exercise 1.6

For a counterexample, if we had these subsets:

- $\{1,2,3,4,5,6\}$
- $\{1,2,3,4,7\}$
- $\{1,2,3,4,8\}$
- $\{1,2,8\}$
- $\{3,4,5,6,7\}$

And we wish to find the set cover of $\{1,2,3,4,5,6,7,8\}$,

Then an algorithm picking the largest subset first would give a suboptimal solution to the *set cover problem*.

The greedy algorithm would always pick $\{1,2,3,4,5,6\}$ first, leaving $\{7,8\}$, which requires at least two of the remaining subsets to cover, for example $\{1,2,3,4,7\}$ and $\{1,2,3,4,8\}$. So the greedy algorithm always requires three subsets.

The optimal solution would be two subsets $\{1,2,8\}$ and $\{3,4,5,6,7\}$.
